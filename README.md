## Projects Included

### ✅ Task 1: Student Grade Tracker
> **Location:** `Task1_StudentGradeTracker/`

A console-based system to manage student grades. Calculates average, highest, and lowest scores. Displays a full summary report with grade assignment.

**Key Concepts:** Arrays, ArrayList, Scanner, Methods

---

### ✅ Task 2: Stock Trading Platform
> **Location:** `Task2_StockTradingPlatform/`

Simulates a basic stock market environment with buy/sell operations, portfolio tracking, P&L reporting, and live price simulation.

**Key Concepts:** OOP, HashMap, Random, LocalDateTime

---

### ✅ Task 3: Artificial Intelligence Chatbot
> **Location:** `Task3_AIChatbot/`

A Java-based AI chatbot using rule-based NLP. Responds to keywords across topics like greetings, Java, AI/ML, jokes, fun facts, and math calculations.

**Key Concepts:** NLP, LinkedHashMap, String processing, Thread.sleep

---

### ✅ Task 4: Hotel Reservation System
> **Location:** `Task4_HotelReservationSystem/`

A complete hotel booking system with 3 room categories (Standard, Deluxe, Suite). Supports booking, cancellation, payment simulation, and detailed receipts.

**Key Concepts:** OOP, Enum, LocalDate, ArrayList

## How to Run Any Project

1. Navigate to the project's `src/` folder
2. Compile all `.java` files:
   ```bash
   javac *.java
   ```
3. Run the main class:
   ```bash
   java <MainClassName>
   ```
