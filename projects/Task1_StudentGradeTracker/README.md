# Task 1: Student Grade Tracker

**Author: NAVEEN MANI PANDEY**

## Description
A console-based Java application to input and manage student grades. It calculates averages, highest/lowest scores, assigns letter grades, and displays a full summary report.

## Features
- Add multiple students with marks for 5 subjects
- Calculate average, highest, and lowest scores
- Assign letter grades (A+, A, B, C, D, F)
- Search student by roll number
- Display class-wide summary report
- Identifies top performer

## How to Run

### Compile
```bash
cd src
javac Student.java StudentGradeTracker.java
```

### Run
```bash
java StudentGradeTracker
```

## Menu Options
1. **Add Student** – Enter student name, roll number, and marks
2. **View All Students** – See full report of every student
3. **Search Student** – Look up by roll number
4. **Summary Report** – Class-wide tabular summary
5. **Exit**

## Technologies Used
- Java SE
- ArrayList
- Scanner (console I/O)
